1、cloud-demo是总工程，负责管理spring-cloud-alibaba、spring-boot、spring-cloud、jdk版本。

2、子工程有gateway、model、services。gateway负责网关控制，model负责管理services工程共同的bean，services负责各个业务层的实现。

3、services中有子模块seata-account、seata-business、seata-order、seata-storage、services-order、services-product，
每个微服务连接各自的数据库，注册到alibaba-nacos进行通过openfeign互相调用。

4、组件alibaba-sentinel用来熔断、限流，alibaba-seata用来管理分布式事务。

5、nacos-server-2.3.2
进入nacos-server-2.3.2\bin，双击startup.cmd，![img.png](D:\heXin\cloud-demo\项目说明png\5d93458f-6a2a-4adb-b666-4fbd09a9c1fd.png)
运行成功后访问http://127.0.0.1:8848/nacos/index.html#/。![](D:\heXin\cloud-demo\项目说明png\注册中心运行成功.png)

6、apache-seata-2.1.0-incubating-bin
进入apache-seata-2.1.0-incubating-bin\bin，运行seata-server.bat，访问http://127.0.0.1:7091/#/login，账户密码都是seata。

7、RESP_app
是一个连接redis的工具，用来查看数据。

8、sentinel-dashboard-1.8.10.jar
java -jar sentinel-dashboard-1.8.10.jar，访问http://localhost:8080/#/login，账户密码都是sentinel。

9、rocketmq-dashboard-2.1.0.zip
先解压，在解压后的文件执行mvn clean package -Dmaven.test.skip=true,执行完毕进入到target目录，找到rocketmq-dashboard-2.1.0.jar，
执行java -jar rocketmq-dashboard-2.1.0.jar即可。访问http://localhost:8082/。
